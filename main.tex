\section{Summary}
We present a Python library for generating and solving differential equations for educational purposes. The system allows students to practise solving equations by automatically generating problems across multiple categories and providing symbolic solutions. The goal is to create an accessible and flexible learning tool for students studying introductory differential equations.

\section{Statement of Need}
Students often require a large number of practice problems to develop confidence in solving differential equations. Although existing tools such as SymPy provide powerful symbolic computation, they are not specifically designed for guided practice. It requires prior understanding and can be time-consuming for users to define problems manually. This project addresses this need by automatically generating valid differential equations and providing corresponding solutions, making it easier for students to practice and learn.

\section{Functionality}
The library supports a range of differential equation types: first-order linear, separable, Bernoulli, second-order constant-coefficient, and systems of equations. Each equation type is implemented in its own module, with two main components: a generator and a solver. The generator creates valid equations by randomly selecting coefficients and constructing expressions that follow known solvable forms. The solver computes symbolic solutions using established mathematical methods.

The system also includes a function to generate complete problem sheets, which can be optionally exported as formatted PDF documents. This allows users to create structured worksheets for practice or teaching purposes.

\section{State of the Field}
Symbolic computation tools such as SymPy offer a wide range of capabilities for solving differential equations. However, they require users to explicitly define equations and are not tailored for generating practice material. Other tools, such as Wolfram Alpha, can solve equations but are not easily programmable or suitable for generating problems in batches. In contrast, this project focuses specifically on automated problem generation and educational use, providing a simpler interface for students.

\section{Testing}
To ensure the software's correctness, a comprehensive suite of automated tests was implemented using the pytest framework. These tests verified that the generated differential equations are valid and that the corresponding solver functions return correct symbolic solutions. The test suite covers all supported equation types and includes a range of cases to ensure robustness. Running tests yielded 118 successful results, confirming that the library's core functionality behaves as expected.

\section{Conclusion}
This project demonstrates a modular and extensible approach to generating and solving differential equations. Combining symbolic computation with automated problem generation provides a useful tool for students and educators. Future improvements could include more detailed step-by-step solutions and support for additional equation types.
